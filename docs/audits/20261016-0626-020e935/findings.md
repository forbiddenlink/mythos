## Remaining dependency observations

- **DEP-001, Low application severity / High version confidence:** live `pnpm audit` reports `braces@3.0.3` through the ESLint/fast-glob development-tool chain. The upstream advisory is labeled High and lists no patched release. No public request path into that tool was established. Keep build/lint patterns trusted and revisit when a patch exists; do not claim the entire dependency tree is clean. [Upstream advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).
- **DEP-002, Low conditional application exposure / High local version confidence:** the locally resolved sharp binary is 0.35.5 with libvips 8.18.7, librsvg 2.63.2 and libheif 1.23.5. The checked sharp/librsvg and libvips advisories are patched at these versions. Several October libheif advisories include 1.23.5 and specify 1.23.6 as patched. The latest npm sharp observed was still 0.35.5. No app upload endpoint or arbitrary image host exists; native decoder availability, hostile-byte reachability and the production Linux binary were not demonstrated. This remains a native-layer follow-up, not a confirmed remotely exploitable app defect. [Sharp/librsvg](https://github.com/lovell/sharp/security/advisories/GHSA-wq5f-xc86-pv6w), [libvips](https://github.com/libvips/libvips/security/advisories/GHSA-9rwc-f68v-4482), [libheif OpenJPEG](https://github.com/strukturag/libheif/security/advisories/GHSA-h4h8-qgvc-m7r2), [libheif conversion](https://github.com/strukturag/libheif/security/advisories/GHSA-q7mw-2fmm-5q94), [libheif CPU amplification](https://github.com/strukturag/libheif/security/advisories/GHSA-6fqc-p7r8-2g36).

## Refuted or unconfirmed candidates

- Missing `actions: read` was not retained as a demonstrated automerge failure: public workflow reads may work without it, and live repository visibility/permissions were not verified.
- Forwarded-client-IP spoofability was not established without the hosting platform's actual header-overwrite contract.
- Persistent Vercel tracking after component unmount was not proven from source injection alone; actual post-rejection network behavior remains uncovered.
- No additional reachable input-validation, origin-check, unbounded-AI-spend or cross-user-data defect was confirmed in the inspected API source. This is a bounded source review, not a blanket security guarantee.

Four read-only area reviewers, including a separate skeptic, checked the candidates. The skeptic reviewed the implemented diff and final narrow follow-up and found no introduced blocker. Test results below come from executed commands, not reviewer opinion.
