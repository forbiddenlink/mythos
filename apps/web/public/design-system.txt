# Mythos (mythosatlas.com) — Design System (AI-readable index)

> Machine-readable token + component contract for AI coding agents (Claude, Cursor, v0).
> Brand: "Classical · scholarly · luminous — dark-academia atlas of antiquity." Calm authority, never neon AI-product energy.
> When generating UI: pick ONLY from the named tokens below. Never emit ad-hoc hex/px.
> Token SoT = apps/web/src/app/globals.css. Philosophy = .impeccable.md (repo root).

Site: https://mythosatlas.com
Stack: Next.js 16.2, React 19.2, Tailwind CSS v4 (@theme inline), shadcn/ui (new-york, base neutral, lucide), cva. Monorepo (pnpm workspace) — app at apps/web/, source apps/web/src/.

## Hard rules (.impeccable.md — 5 principles)
- Named theme tokens over hardcoded skins. Brand-first. Depth on FEW surfaces (prefer manuscript lists/prose over card-soup; cards only for interactive/structured data). Atlas-like interactivity. Non-negotiable accessibility.
- Hero: one cinematic hero ("The Atlas Opens"); brand name IS the hero signal; ≤2 ambient motion systems; scroll-scrub GSAP not idle GPU spam.
- Motion: purposeful only; prefers-reduced-motion collapses to static; transform/opacity only.
- Anti-references (banned): purple/indigo SaaS gradients, Lucide-in-gradient-square feature grids, slate/amber stock heroes, stacked identical cards, glow-ring icon badges as brand mark, flat single-color backgrounds without atmosphere.
