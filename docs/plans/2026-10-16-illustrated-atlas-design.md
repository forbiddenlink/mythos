# Illustrated atlas visual refinement

The user requested a candid visual review and improvements, explicitly asking to avoid a generic AI appearance. They chose the recommended direction: an illustrated atlas with authentic artwork and restrained motion.

The live site already has distinctive classical typography and an editorial grid. Its largest weakness is the prominence of generic fantasy imagery, followed by a long first section on mobile. A source mismatch also hides all featured traditions from the homepage.

This pass keeps the existing brand and tokens. It replaces the homepage's generated Zeus painting with the documented Nataraja photograph already in the museum catalog, including exact title, date and source credit. Deity pages prefer suitable documented museum objects before illustrative fallbacks. The opening index previews six traditions with a direct route to all 26. Featured traditions return as one plate and a compact manuscript list. Mobile comparisons show two curated groups with the full comparison catalog linked. Image zoom and arrow feedback respect reduced motion.

The image optimizer permits only the documented Met image host/path in addition to the existing Met API source. No new image generation, dependency, account flow or animation library is added. Existing illustrations remain honestly labeled; this pass does not claim the entire catalog has become historical artwork.
