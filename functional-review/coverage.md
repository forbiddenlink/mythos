# Functional review

2026-09-28. Local production build initially at `http://127.0.0.1:3000`, final isolated verification at `http://127.0.0.1:3002`; Node 22.23.1 (installed compatible Node 22 runtime), pnpm 10.34.5. No deployment, real newsletter submission, payment, or live AI request was made. Build-time Sentry uploads were disabled.

## Product and scope

Mythos Atlas is a public encyclopedia with browser-local learning. First-time readers browse and read; returning readers save entries, track progress and review. There are no account roles, private server records, admin UI, subscription entitlements or application background jobs to test. The active monorepo app is `apps/web`; pages read static catalogs in `src/data`, with entity interfaces and validated Zod schemas. Relationships connect deities, stories, pantheons, places and learning cards. The retired `apps/api` is excluded and untouched. Generated output, dependencies and vendored code are excluded from source review.

Expectations derive from README, ARCHITECTURE.md, visible UI and previous design/auth reports: browsing needs no account; learning persists in the same browser; backups transfer four learning categories; review derives from viewed/read entries; unavailable optional integrations must not claim success. Failed operations must preserve recoverable intent and accurately report their outcome. Cross-device sync is an optional hypothesis, not an existing promise.

The independently enumerated 66 page templates match the earlier design inventory, with no missing or additional templates. This pass also enumerates 11 route handlers. `inventory.json`, `api-inventory.json` and `page-evidence.json` preserve paths and observations. All 66 templates plus an invalid deity route were visited at desktop 1440px and mobile 390px: 134 captures, no page JavaScript errors, no document-width overflow, and no broken images among loaded images. Offscreen descendants in clipped progress bars, graph canvases and horizontal control scrollers are recorded in the raw evidence and are not document overflow. Contact sheets of all captures were visually inspected. This is template coverage, not exhaustive verification of every record or control.
