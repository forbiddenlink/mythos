# Mythos (mythosatlas.com) — Design System (AI-readable index)

> Machine-readable token + component contract for AI coding agents (Claude, Cursor, v0).
> Brand: "Classical · scholarly · luminous — dark-academia atlas of antiquity." Calm authority, never neon AI-product energy.
> When generating UI: pick ONLY from the named tokens below. Never emit ad-hoc hex/px.
> Token SoT = apps/web/src/app/globals.css. Philosophy = .impeccable.md (repo root).

Site: https://mythosatlas.com
Stack: Next.js 16.3.4, React 19.2, Tailwind CSS v4 (@theme inline), shadcn/ui (new-york, base neutral, lucide), cva. Monorepo (pnpm workspace) — app at apps/web/, source apps/web/src/.
Colors = OKLCH in :root (light) + .dark.

## Layout grid (globals.css + apps/web/src/components/layout/)
- Container widths: reading 68ch · content 1200px · wide 1360px (Tailwind: max-w-reading / max-w-content / max-w-wide).
- Gutters (--gutter): 16px phone, 24px ≥640, 32px ≥1024. Section spacing: --section-space-sm/-/-lg = 48/72/96px desktop (40/56/72 phone).
- <Container size="reading|content|wide"> — every section sits in one so edges align header → footer (.layout-container).
- <Section spacing="sm|md|lg" tone="default|muted|dark" size> — vertical rhythm + Container. tone="dark" scopes the .dark tokens.
- <SectionHeading eyebrow title description action={{href,label}} as="h2|h3" id align> — the ONLY section-title treatment. No left bars, no icon-per-heading.
- <PageHeader eyebrow mark title lede count actions image imageAlt breadcrumbs accent> — compact index header with the breadcrumb built in; with `image` it is a short midnight band. <PageHero> (legacy props: tagline/description/backgroundImage) renders it; don't add <Breadcrumbs/> under either.
- <AboutThisPage title defaultOpen size> — native <details> below the content for "how to use"/SEO explainer text. Never put explainer boxes above the tool/grid.
- Entity pages: <DetailLayout hero facts toc aside after asideLabel> + <DetailHero image imageCaption eyebrow title titleAddon nativeName epithets tags lede actions meta accentColor> + <ArticleSection id title eyebrow description reading> + aside blocks <FactList facts/>, <OnThisPage items/>, <RelatedFigures figures/>, <AsideLinks title links/>. Reference implementation: app/deities/[slug]/page.tsx.
- Parallel figures: components/mythology/ParallelFigures.tsx (variant annotated|portraits; aria-label ends "across pantheons").

## Chrome
- Header: always-solid bar, 64px, content-width grid; nav triggers and icon controls are 40px; the current section shows a 2px gold underline (aria-current on links).
- Footer: brand + newsletter column and four link columns, compact; optional tools (random deity, Oracle, audio, notifications) in one row; no decorative image band above it.

## Imagery
- Lead with portraits: catalog images via next/image (fill + sizes), 4:5 for figures, 3:2/4:3 for places. Never show a grey placeholder or an icon as content; fall back to the figure's initial.
- Procedural "plates" (drawn by code) are stand-ins; don't feature them in hero/showcase slots.

## Hard rules (.impeccable.md — 5 principles)
- Named theme tokens over hardcoded skins. Brand-first. Depth on FEW surfaces (prefer manuscript lists/prose over card-soup; cards only for interactive/structured data). Atlas-like interactivity. Non-negotiable accessibility.
- Hero: one cinematic hero ("The Atlas Opens") in normal document flow; brand name IS the hero signal. Show browse/read actions immediately. No pinned scenes, nested hero scrolling, or decorative WebGL.
- Optional audio, discovery, and Oracle controls live in the footer, not floating over content. Achievement notifications default off.
- Motion: purposeful only; prefers-reduced-motion collapses to static; transform/opacity only.
- Anti-references (banned): purple/indigo SaaS gradients, Lucide-in-gradient-square feature grids, slate/amber stock heroes, stacked identical cards, glow-ring icon badges as brand mark, flat single-color backgrounds without atmosphere.
