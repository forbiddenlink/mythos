# QA, bug hunt, and reader journeys — October 16, 2026

Local verification of Mythos Atlas using Node 22.23.1 (within the project's Node 22 engine range), pnpm 10.34.6, and a production webpack build. Existing untracked research reports were preserved. No deployment, real payment, newsletter submission, or live Oracle request was made.

## Confirmed bugs fixed

1. **Daily review statistics carried yesterday's answers across midnight.** An open session could show two reviews today after answering one card before midnight and another afterward. Review writes now reset daily answers on the new local date; today's statistics also disregard the previous day's answers before the next review. Lifetime totals and consecutive-day streaks remain intact.
2. **Cards due again today remained excluded in an open tab.** Generating a deck after midnight still treated yesterday's reviewed card IDs as reviewed today. Deck generation and due counts now apply that exclusion only when the saved review date is today.

Both new provider regressions fail against the original implementation and pass with the fix. A mobile browser regression also reproduced the original visible count error in a real review session, using New York's local midnight rather than UTC midnight.

The homepage lazy-fact unit test also timed out intermittently while its dynamic import was still loading. It now waits for the import to settle inside React's update boundary, retaining its assertions against the real component.

Changes are limited to the review provider, its unit tests, the review recovery browser tests, and the lazy-fact unit test.

## Page and link inspection

The template sweep and link/image inventories used the initial production build. The full final Chromium suite and final cross-browser journeys use the rebuilt implementation, including the review fix.

The page sweep exercised all **69 current page templates**, including representative dynamic records and the newsletter, goddess, and creature hubs. Each ran at **320, 768, and 1440 pixels in light and dark themes: 414 cases**. Every case returned 200 and had one visible main heading. There were no reported WCAG A/AA rule violations, document-width overflow, nested interactive controls, or page JavaScript exceptions. Representative screenshots were visually inspected; this does not claim human inspection of every screenshot.

The raw scanner flagged incomplete images in five cases: facts at 320 pixels and family tree at 768/1440 pixels. Its visibility check included offscreen or clipped lazy thumbnails. A follow-up scrolled both pages in both themes at all three widths, checking individual images that intersected the viewport and ancestor clipping regions: **12 cases, zero visible image failures**. The raw findings remain in the evidence rather than being silently discarded.

Server-rendered links across the 69 representative pages produced **1,349 unique internal paths**. Of those, 1,344 matched prerendered routes or actual public files; the remaining five were checked over HTTP and returned 200. No missing same-page fragment targets were found. Manifest matches establish destination existence, not exhaustive behavior at every destination; cross-page fragment targets and external citations were not exhaustively checked.

## Diagnostic history and limits

The first Chromium run passed 253/256 checks; three search-opening checks timed out under concurrent local load. All eight search tests passed in isolation. The first Firefox/WebKit subset passed 60/62; a Firefox page-load timeout and a WebKit interrupted navigation both passed in an isolated four-case rerun. These initial failures are retained separately from final verification. Final reruns passed all 257 Chromium tests and all 64 Firefox/WebKit journey tests without retries.

An initial unit run with default worker concurrency was interrupted after several timeouts. A controlled run isolated the lazy-import test's race; after fixing that test, the full coverage run passed. No assertions, coverage thresholds, or lint rules were weakened.

Framework diagnostics still include an Edge Runtime deprecation and response close-listener warnings during browser testing. An internal `NoFallbackError` was also logged during invalid-entry recovery; a direct follow-up request confirmed that the invalid entry correctly returned HTTP 404. No page exceptions were observed in the template sweep. Their underlying framework causes were not established by this review; these diagnostics are not represented as fixed.

This is local functional and automated accessibility verification, not exhaustive editorial fact-checking, a security audit, physical-device testing, or screen-reader testing. WebKit testing does not establish coverage of every Safari/OS version. Optional external services were mocked or exercised only in their unavailable state. Every content record and every visualization gesture was not individually exercised.

Raw logs and the compact page/link/image summary are retained locally under `functional-review/evidence/2026-10-16/` (ignored by Git). The 414 raw page captures and results are under `/tmp/mythos-qa-sweep/`; they are regenerable local evidence and are not included in repository changes.
