# Product findings and improvements

2026-09-28. Evidence comes from the current app, targeted failure injection, the existing tests and the product's documented browser-local learning promise. No measured retention or conversion claims are made.

The first-time reader can browse, read and save without an account. The returning reader has bookmarks, review and backup/restore. There is no administrator role or application billing entitlement to extend. No redesign or generic feature backlog is proposed.

Implementation reference: [Radix Popover official documentation](https://www.radix-ui.com/primitives/docs/components/popover), inspected 2026-09-28, covers collision handling, portals, available-height sizing and managed focus. The installed `radix-ui` package already exports Popover; no dependency was added.
