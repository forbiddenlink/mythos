# Reader-impact baseline, 2026-10-16

Snapshot as of 2026-10-16. Recheck on **2026-11-13** (28 days after the fixes
below reach production, so the comparison window does not overlap this one).

## Where the numbers come from

- **Google Search Console**, property `https://mythosatlas.com/` (URL prefix,
  not a domain property), Performance, Web, last 28 days, read 2026-10-16.
- **PostHog** project 626790, HogQL over the last 30 days.

## Finding 1: PostHog cannot be the baseline yet

| Event (30 days) | Count  | Distinct ids |
| --------------- | ------ | ------------ |
| `web_vital`     | 20,584 | 1,796        |
| `$pageview`     | 46     | 9            |
| `entry_viewed`  | 3      | 3            |

`web_vital` arrived only on four days (09-28: 1,193, 10-01: 7,696,
10-08: 815, 10-16: 10,825) and on no other day. 10-16 matches four local
Playwright runs. Cause: a local `next build && next start` inlines the same
public PostHog key, it is not `NODE_ENV=development`, and the Playwright config
pre-accepts cookie consent, so every test page reported to the production
project.

Fix: `src/lib/analytics/production-host.ts`. The PostHog SDK and the
web-vitals reporter run only on `mythosatlas.com` / `www.mythosatlas.com`.
Tests prove local hosts send nothing.

Search Console counted 670 search clicks in the same window, against 9
consenting PostHog visitors. Even with test traffic gone, consent-gated
analytics will see only a small share of readers. See "Decision needed" below.

Events recorded before this fix reaches production are polluted: treat
PostHog data before the deploy date as unusable.

## Fixes shipped against this baseline

1. Analytics record production only (Finding 1).
2. Tradition hubs titled "<Tradition> Mythology: Gods and Myths"
   (`traditionHubTitle` in `lib/metadata.ts`). Was "<Name> Guide".
3. Collections titled by their best-known members
   ("Trickster Gods: Loki, Hermes, Anansi and More"); snippet leads with five names.
   Was "Trickster Gods Collection".
4. Locations titled "<Place> in <Tradition> Mythology". Was "<Place> - <Tradition> Location".
5. Hub snippets cut at a sentence or word with an ellipsis, not mid-word.

## What to measure on 2026-11-13

- `/pantheons/*` CTR from 0.5%, and whether `/pantheons/haudenosaunee`
  replaces the Three Sisters story for "haudenosaunee mythology".
- `/collections/*` and `/locations/*` CTR from 0.5%.
- "trickster gods" CTR from 0.6%; "lake avernus" from 0%.
- Positions should not drop; a title change that lowers position is a regression.
- PostHog: `web_vital` should arrive every day in small numbers, with no bursts
  on test days.

Earliest honest verdict is the 2026-11-13 read: Google rewrites titles over
days to weeks, and one week inside the window proves nothing.

## Decision needed (not made here)

Consent-gated analytics will keep missing most readers. PostHog's cookieless
mode counts anonymous page views without storing anything on the device, which
can run before consent. It changes what the privacy policy promises, so it is a
policy decision for the site owner, not a code change to slip in.
